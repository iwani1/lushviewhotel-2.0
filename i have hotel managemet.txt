4. Check for updates without installing them
If the directory is a Git repository, run:

git fetch origin --prune --tags

This downloads GitHub's latest branch and tag information without replacing your installed application files.

If your branch is develop, you can inspect the available updates using:

git log --oneline HEAD..origin/develop

And inspect the size of the changes:

git diff --stat HEAD..origin/develop

Do not run git pull, git reset or git checkout yet.
